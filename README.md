# 📚 Sistema de Biblioteca

## 📖 Sobre o projeto

O Sistema de Biblioteca é uma aplicação web desenvolvida com o objetivo de facilitar o gerenciamento de livros e empréstimos em uma biblioteca.

O sistema possui duas interfaces principais: uma destinada ao bibliotecário e outra ao leitor, cada uma com funcionalidades específicas para facilitar a organização e o acesso aos livros.

## 🚀 Funcionalidades

### 👨‍💼 Bibliotecário
- Cadastro de livros.
- Registro do nome do livro.
- Definição da quantidade de exemplares disponíveis.
- Registro de data relacionada ao cadastro do livro.
- Gerenciamento dos livros cadastrados.

### 📖 Leitor
- Criação de conta na plataforma.
- Acesso à área do leitor.
- Consulta aos livros disponíveis.
- Solicitação de empréstimo de livros.

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **JavaScript:** linguagem de programação utilizada no desenvolvimento do sistema.
- **Node.js:** ambiente de execução JavaScript no backend.
- **Express:** framework utilizado para estruturar o servidor e as rotas.
- **HTML:** estruturação das páginas.
- **CSS:** estilização e aparência da interface.
- **MySQL:** banco de dados utilizado para armazenar as informações.
- **MySQL Workbench:** ferramenta utilizada para trabalhar com o banco de dados.

## 📁 Estrutura do projeto

- `backend/` — arquivos responsáveis pelo funcionamento do servidor e processamento das funcionalidades.
- `frontend/` — arquivos responsáveis pelas interfaces e interação com os usuários.
- `EstruturaSql.sql` — arquivo contendo a estrutura do banco de dados.

## 📌 Objetivo do projeto

Desenvolver uma aplicação que facilite o gerenciamento de uma biblioteca, permitindo que o bibliotecário organize os livros cadastrados e que os leitores possam criar suas contas e solicitar empréstimos.
